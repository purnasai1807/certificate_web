FONT BUNDLE FIX

The Python Vercel Function explicitly includes public/fonts/** via vercel.json.
This is required because the PDF renderer runs inside the Python serverless function;
frontend static assets being available does not guarantee the same files are packaged
inside the Python Function.

All bundled certificate fonts remain in public/fonts and are used by the PDF renderer.
Noto Sans Hebrew and the other 40 families are therefore available to the server-side
PDF generator after deployment.
